# Build the Lumina APK
1. Install Android Studio (free).
2. File > Open > choose this `android` folder. Let Gradle sync (it downloads what it needs).
3. Plug in your phone (USB debugging on) and press Run, or Build > Build APK(s).
4. The APK is at app/build/outputs/apk/debug/app-debug.apk. Copy it to your phone and install it.
The web app lives in app/src/main/assets/www. Edit it there, rebuild, done.
Exports (PNG, .cube, contact sheet) are saved to your Downloads folder.
